# 05 · 前端 UI 规范

## 风格定位
企业级 SaaS 后台管理系统（Enterprise Admin Dashboard）· 现代管理控制台 · 数据驱动后台 · 极简商务 UI · 云管理平台 · **蓝色科技感**。

- **布局**：经典左右布局 —— 左侧固定 `Sider`（深色或浅色可切，含 Logo + 菜单）+ 顶部 `Header`（面包屑 / 全局搜索 / 余额 / 消息 / 用户下拉 / 主题切换）+ 右侧 `Content`。用 Ant Design `ProLayout`。
- **配色**：主色 `#1677ff`；成功 `#52c41a`、警告 `#faad14`、错误 `#ff4d4f`；背景 `#f0f2f5`；卡片白底、圆角 8px、`box-shadow: 0 1px 2px rgba(0,0,0,.06)`。可选深色侧边栏 `#001529`。
- **字体/密度**：系统无衬线；信息密度适中，留白充足；数字用等宽或 `tabular-nums`。
- **组件**：指标卡（Statistic + 迷你趋势）、`ProTable`（分页/筛选/导出）、`ProForm`、`@ant-design/charts`（折线/柱/环形）。

## 关键页面交互
- **创作中心**：顶部模式切换（文生图 / 图生图 / 文生视频 / 图生视频），下拉只出该模式的正式模型（见 [13-models](./13-models.md)）。模型项含单价；`submit_ready=false` 标明未接入上游。图生图最多 8 张参考图、图生视频最多 4 张（面板上限）。提交后任务卡通过 SSE/WS 显示 `queued→running→succeeded`，结果内联预览、下载、复用参数。余额不足前置拦截。
- **数据统计**：顶部指标卡（**今日/合计生成**、**今日/合计收入**、可用票据、**可用积分 剩余/总额** + **号池 总数/可用**）+ 主趋势折线（横轴本地 `HH:mm`）+ 出口健康（最近 5 个）。
- **请求日志**：只读、脱敏。列表按任务 ID 归并一行，**提交后立刻出现**（不必等上游结束）；筛选图片/视频、成功/生成中/失败、用户名（无展开收起）。详情展示该任务每次请求的原始响应，结果预览支持图片和视频。清理下拉：失败 / 三天前 / 全部。不展示 Cookie/Token。
- **号池管理**：顶部四张卡为全站汇总（账号 / 可用积分 / 冷却中 / 积分号），不受分页和筛选影响。筛选查询行右侧为刷新、导入、导出、删除所选。行操作含编辑、验证（凭据+积分，代理 TLS 最多 3 次）、启用/停用。导出按当前筛选下载 `邮箱----Cookie`（或纯 Cookie）文本，不写日志。
- 顶栏铃铛：点击弹出系统配置里的平台公告；无公告显示空态；有未读公告时红点，点开后消除。
- 侧栏页脚：`技术：闲的无聊` / 开源 `https://github.com/432539/adobe` / `技术支持 QQ 群 1109037692`。登录页、调用说明、个人设置同样展示开源地址与群号。
- **调用说明**：OpenAI / Gemini 标签页；每个标签提供同步、异步、图片编辑、视频示例和一键复制；显示当前 base URL、KEY 前缀及模型能力矩阵。

## 视觉质量验收
- 统一 8px 网格、12/16/24px 间距阶梯；内容区最大宽度与大屏自适应并存，避免超宽表单。
- 所有页面都有 loading skeleton、empty、error、无权限、移动端降级状态；交互有 hover/focus/disabled。
- 图表颜色和状态颜色语义固定；不能只靠颜色区分状态，需同时有图标/文字。
- 首屏避免“大面积空白 + 一堆表格”：仪表盘按“关键指标 → 趋势 → 系统健康 → 最近任务”形成视觉层级。
- Lighthouse（生产构建）性能/可访问性目标 ≥ 90；主路由懒加载，图表和编辑器按需加载。

## 工程约定
- Vite + React 18 + TS 严格模式；`react-router` v6 角色分区路由；`@tanstack/react-query` 管服务端态；`zustand` 管轻量全局态。
- `services/http.ts` 统一 axios：注入 JWT、401 跳登录、全局 `message.error`。
- 主题用 antd v5 `ConfigProvider` token，不散落魔法色值；响应式 `xs~xxl`。
- 金额/积分展示由后端最小单位换算显示，前端不做计费判断；不存任何上游密钥。
